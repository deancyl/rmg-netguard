# WebUI 使用

## 页面结构

顶部 sticky 状态条始终显示：

- 当前健康状态；
- 实时模式；
- 当前轨道；
- AGH 进程与端口状态；
- 最近一次过滤探针；
- 后台快照年龄。

快照年龄逐步增长是正常现象。模块后台默认每 90 秒采样一次；WebUI 的 30 秒自动
刷新只读取最近快照和实时 controller 状态，不会每次都执行慢速 DNS 探针。

## 操作反馈

点击任何动作都会立即出现结果带：

- 蓝色：命令已发送、正在执行；
- 绿色：命令成功；
- 红色：命令返回非零退出码或明确失败；
- 黄色：需要用户处理或当前有任务运行。

执行期间按钮被锁定并显示秒数。若桥接回调超过 90 秒没有返回，页面会解除锁定并
显示超时错误。

## 模式

### 只看不动

不上传网络规则，只记录状态。适合：

- 首次安装；
- 排查 DNS / VPN 问题；
- 暂不信任自动切换；
- 需要让当前拓扑保持不变。

### 自动切换

VPN 状态连续两轮稳定后才动作：

- VPN 开启：摘除 `OUTPUT -> ADGUARD_REDIRECT_DNS`；
- VPN 关闭：恢复该跳转。

每次动作前都会检查 AGH 进程和 5591 应答。健康门控失败时不做切换，并在事件日志
记录原因。

## DNS 集成

启用后，模块把 Clash Meta 活动 profile 的 `nameserver` 指向
`127.0.0.1:5591`。

流程：

1. 找到活动 profile；
2. 保存首份原始备份；
3. 通过临时文件重写，保留 uid 与 SELinux context；
4. 写入 md5 标记；
5. guard 检测订阅更新造成的漂移并重打。

关闭集成时从首份备份还原。若备份自身含 `NS5591`，模块拒绝还原，避免污染备份。

## 常用按钮

| 按钮 | 是否修改网络 | 说明 |
|---|---|---|
| 刷新状态 | 否 | 完整采集，包含过滤探针 |
| 一键体检 | 否 | 网络、端口、DNS 和拓扑检查 |
| 规则审计 | 否 | 检查 profile 与规则风险 |
| 拦截统计 | 否 | 读取 AGH querylog 近段统计 |
| 事件日志 | 否 | 最近 20 条模块事件 |
| 摘除劫持 | 是 | 只移除一条 nat OUTPUT jump |
| 恢复劫持 | 是 | 在 nat OUTPUT 位置 1 插入 jump |

## 探针解释

- `BLOCKED`：测试域名被 AGH 拦截；
- `OPEN`：测试域名得到真实解析；
- `UNKNOWN`：没有拿到可判定应答；
- `SKIP`：AGH 未运行或不可用。

`BLOCKED / UNKNOWN` 只显示“双探针结果不一致”。它可能是单域名策略、缓存或 UDP
超时，不能单独证明 AGH 整体退化。querylog 年龄较大也可能只是设备没有新查询。
